# Что относится только к исходной системе

| У Антона сделано так | При внедрении у себя |
|---|---|
| Linux, systemd user services, Chrome, установленные Claude/Codex | На Linux адаптировать шаблоны; на Windows — отдельные пути и Task Scheduler, на macOS — launchd. Это ещё не реализованные порты |
| По умолчанию Codex, Sonnet маршрутизирует и принимает, Opus эскалирует | Выбрать доступных провайдеров и бюджет; менять правила вместе с кодом и тестами |
| Конкретные ID моделей и наборы effort | Проверить в своей CLI; не считать доступными по наличию названия в исходнике |
| B24U только Claude Opus через Кокоса | Индивидуальное правило бизнеса Антона. Удалить или заменить, если не нужно; затрагивает routing.py, runtime.py, auth_bridge.py, frontend, ROUTING.md и тесты |
| Тексты от имени Антона → Claude | Личное предпочтение, не техническое требование |
| `from: 'anton'`, тексты «нужен Антон» | Внутреннее имя роли/подписи. Можно сохранить протокол, заменив подписи, либо изменить согласованно во всех компонентах |
| Киви — существующий уведомляющий бот; Кокос — настроенный агент | Они не поставляются. Подключить собственные адаптеры/агентов |
| Общий бот для уведомлений и Claude Telegram | Проще отдельный бот. Relay нужен только при совместном использовании |
| Рабочее дерево `ClaudeAIAgent/AIAgent`, контекст в CONTEXT.md | Организовать свои папки. Основные пути уже вынесены в settings.py; sync и graph всё ещё адаптеры исходной структуры |
| Карта с направлениями работа, обучение, Linux, бизнес | Заменить BRANCHES, реестры агентов, навыки и диагностики в сборщике; реальный граф не опубликован |
| Sync читает планы, проекты, инструменты и Python-скрипты | Сделать явный разрешённый список; иначе возможна выгрузка приватного текста и секретов из кода |
| Специальная ссылка `agentdesk://authorize` открывает браузер | Нужна регистрация обработчика URI на своей ОС; один auth_bridge.py его не регистрирует. Обычная HTTPS-ссылка остаётся доступна |
| Claude CLI запускается с bypassPermissions, Codex с широкими правами | Осознанный выбор автономии исходной установки. Начинать с изолированной папки и разрешённых инструментов; флаги меняются в runtime.py |
| CLI авторизованы по подпискам; API-ключи удаляются из окружения дочернего процесса | Установить и авторизовать свои CLI. Это не перенос подписки и не обещание отсутствия лимитов |

## Изменения именно в экспортной копии

- Исходники Dashboard и AgentDesk объединены в один новый репозиторий без истории рабочих репозиториев.
- Удалены исходный Firebase config, личные пути и несколько клиентских примеров. `YOUR_*`, `/home/USER`, `/path/to/workspace` — заполнители.
- Основные пути AgentDesk и URL доски задаются через `settings.py` / окружение.
- Добавлены шаблоны служб, конфигурации и инструкция для AI.
- Firestore/Storage rules изменены с «любой авторизованный» на конкретный UID владельца.
- Исходные STATE.md, документы контекста, пользовательские инструкции, приватные навыки, карточки, скриншоты, графы и журналы исключены.
- Оставлены исходные названия ролей и примеры структуры, чтобы объяснить механику и места адаптации. Не утверждается, что все интеграции универсализированы.

Живая установка не менялась. Экспорт — отправная точка, развивать его можно независимо.
